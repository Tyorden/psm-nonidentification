# PSM Non-identification

Code and results for the paper:

> **The optimal price point is not identified: a constructive impossibility result for the Van Westendorp Price Sensitivity Meter**
> Tyler Orden, 2026.

The paper constructs an explicit witness: two respondent populations that
produce identical Van Westendorp PSM curves (hence the same Optimal Price
Point) while their revenue-optimal prices differ, so no functional of the PSM
output can recover the optimal price. The witness is certified by
exact-rational verification, extended to continuous populations by Monte
Carlo, and complemented by a positive result characterizing when a declared
measurement equation restores identification.

## Repository layout

```
scripts/   Verification pipeline (Python 3): 00 to 03 plus the shared psm_core module
results/   Every result file cited in the paper
```

## Data sources

None. The paper is a mathematical construction; every number is generated by
the scripts from explicit distributions with fixed seeds. No external data,
APIs, or keys are involved.

## Reproduction

Requirements: Python 3 with `numpy` (and `matplotlib` for the figure in
script 02). All scripts are deterministic given their fixed seeds and
regenerate the results byte-identically. Run from `scripts/`:

```
python 00_anchor.py               # correctness anchor: recovers the hand-solved
                                  # uniform example (OPP 8, IPP 8, PMC 7, PME 9)
python 01_nonidentification.py    # builds the discrete witness and certifies the
                                  # theorem (01_counterexample.json, 01_curves.csv)
python 02_monte_carlo.py          # both continuous experiments (02_monte_carlo.json,
                                  # 02_figure.png)
python 03_witness_certificate.py  # re-certifies the witness on a full-support grid
                                  # and by exact atom enumeration; computes the
                                  # positive-result quantities
                                  # (03_witness_certificate.json, 03_curves_full.csv)
```

The verification logic lives in `psm_core.py`; script 00 validates it against
an analytically solved example before anything else depends on it. The witness
generator in script 01 is parameterized so a skeptical reader can construct
further counterexamples.
